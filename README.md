# IoT Smart Traffic Light System

## About
An IoT-based smart traffic light system designed and simulated using **Cisco Packet Tracer**. The project uses simulated motion sensors to detect pedestrian and vehicle movement and automatically control traffic signals. It also includes an IoT server, laptop, and street camera for monitoring the simulated environment.

## Technologies Used
- Cisco Packet Tracer
- Internet of Things (IoT)
- Simulated Motion Sensors
- Traffic Lights
- IoT Server
- Street Camera
- Laptop for Monitoring

## Features
- Simulates pedestrian and vehicle detection.
- Automatically changes traffic signals based on sensor activity.
- Displays white when neither sensor detects movement.
- Gives green to the detected side and red to the other side.
- Includes a simulated camera and laptop for traffic monitoring.

## How It Works
1. Simulated motion sensors detect pedestrian and vehicle movement.
2. When neither sensor detects movement, the traffic lights display white.
3. When pedestrians are detected, their signal turns green while the vehicle signal turns red.
4. When vehicles are detected, their signal turns green while the pedestrian signal turns red.
5. The IoT server, laptop, and camera support monitoring within the Packet Tracer simulation.
